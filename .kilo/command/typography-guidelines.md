# Typography Guidelines

## TYPOGRAPHY SCALE — IMPORTANT

The very large hero typography used on the HOME page must be exclusive to the HOME page.

Do NOT reuse the Home page hero text size anywhere else on the website.

Specifically:

- The Home page may use the largest display/hero typography.
- All other pages must use a smaller, appropriate heading scale.
- Project pages must NOT use the same oversized typography as the Home hero.
- Photography page must NOT use the Home hero text size.
- Blog page must NOT use the Home hero text size.
- CV page must NOT use the Home hero text size.
- Contact page must NOT use the Home hero text size.
- About/Approach sections must NOT use the Home hero text size unless they are part of the Home page hero itself.

Create a clear typographic hierarchy between:
1. Home hero — largest
2. Home section headings
3. Internal page headings
4. Project/page titles
5. Subheadings
6. Body text
7. Labels / metadata

The Home hero should feel visually distinctive because of its scale.

Internal pages should feel more restrained and editorial.

Do not simply copy the Home hero typography settings into other pages.

Use responsive sizing appropriate to each page and viewport.

The typography must remain the established font throughout the website.

Do not change the font family.

Do not introduce another typeface.

The goal is:
HOME = bold, large, distinctive

INTERNAL PAGES = refined, readable, appropriately scaled
